## ПРИМЕРЫ КОДА ДЛЯ СОБЫТИЙ

### Торговец (Map012, EV008):
```javascript
// Проверяем текущий этап квеста
var questStage = $gameVariables.value(20);

if (questStage == 1) {
    // Начало квеста
    $gameMessage.add("Приветствую! Мне нужны ракушки для дочери.");
    $gameMessage.add("Соберите 5 ракушек на берегу, и я дам вам баллон.");
    $gameVariables.setValue(20, 2);
    $gameVariables.setValue(21, 0); // Обнуляем счетчик
} 
else if (questStage == 2) {
    // Проверяем, собрал ли игрок ракушки
    if ($gameVariables.value(21) >= 5) {
        $gameMessage.add("Отлично! Вот ваш баллон.");
        $gameVariables.setValue(20, 3);
        // Выдать баллон игроку
    } else {
        $gameMessage.add("Еще нужно " + (5 - $gameVariables.value(21)) + " ракушек.");
    }
}
else if (questStage == 3) {
    // Уже получил баллон
    $gameMessage.add("Идите к работнику в доках за ластами.");
}
```
